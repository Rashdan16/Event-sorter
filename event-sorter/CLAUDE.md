# Claude Code Instructions

## Response Style

- After making changes, always provide a **summarised explanation** of what was changed and how it was done. Keep it concise — bullet points or short paragraphs are preferred over long walls of text.

## Error Fixes

- When fixing an error or bug, always explain:
  1. **What the issue was** — the root cause of the error
  2. **How it was fixed** — the approach taken to resolve it
